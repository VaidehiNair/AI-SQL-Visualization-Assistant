This project is an end-to-end AI-powered assistant designed to bridge the gap between natural language queries and actionable data insights. Built with Python, Streamlit, and cutting-edge LLMs like Llama 3 and PandasAI, the system allows users to ask questions about their data in plain English and receive accurate SQL results, dynamic visualizations, and concise textual summaries.
At its core, the application features a multi-stage AI workflow. First, user queries are parsed by an LLM to extract SQL intent and chart instructions. The system then safely generates and executes SQL queries against a MySQL database while ensuring compliance with the schema and preventing destructive operations. Results are automatically converted into Pandas DataFrames, with support for data type conversions such as Decimal to float.
For visualization, the assistant generates dynamic charts using Matplotlib and PandasAI, supporting bar, line, pie, area, and scatter plots. Charts are created using all available data, with automated figure sizing, and saved for frontend rendering. Each chart is accompanied by an AI-generated textual description summarizing key insights in plain language, making complex datasets easily understandable to non-technical stakeholders.
The workflow also includes rigorous validation steps. Generated Python code is checked for syntax, security, and completeness before execution. JSON outputs for visualizations are validated to ensure safe and consistent rendering in web frontends. This guarantees reliability, reproducibility, and frontend safety.
The user interface, built-in Streamlit, offers a seamless, interactive experience. Users can enter queries, view SQL results, examine visualizations, and read AI summaries in a single interface. The system effectively reduces manual effort for data exploration and reporting, enabling quick decision-making without deep technical knowledge.
This project demonstrates the integration of AI, SQL, and visualization workflows into a single platform, highlighting the potential of LLMs to enhance data accessibility and operational efficiency.
